# Analog Clock

A modern and responsive Analog Clock application built using HTML, CSS, and JavaScript. The clock displays the current time in real-time with smoothly animated hour, minute, and second hands, closely replicating the behavior of a traditional wall clock.

## Overview

This project demonstrates the use of JavaScript Date APIs, CSS transformations, and responsive web design principles to create an interactive analog clock. It is lightweight, fast, and does not rely on any external libraries or frameworks.

## Features

- Real-time clock synchronization
- Smooth and accurate hand movement
- Responsive design for desktop and mobile devices
- Clean and modern user interface
- Pure JavaScript implementation
- Lightweight and easy to customize

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
